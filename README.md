## Project Structure

```text
public/
├── assets/       Images, presentations, videos, icons and résumé files
├── play/         Personal and creative pages
├── projects/     Individual project and event pages
├── scripts/      Client-side JavaScript
├── skills/       Legacy skill-detail pages
└── styles/       Shared site styling
routes/           Express route handlers
server.js         Express server and static-file configuration
```

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server with automatic restarts:

```bash
npm run dev
```

Or run the standard server:

```bash
npm start
```

The site will be available at [http://localhost:3000](http://localhost:3000).
